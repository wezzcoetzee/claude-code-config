# UI and UX

Interfaces are where personality lives. Treat every UI or UX change as a chance to make something people enjoy using, and design it bold.

## Color

- Choose a vibrant palette with a clear point of view: saturated primaries, confident gradients, rich accents.
- Give color jobs: brand, state, emphasis, grouping. A screen with several colors doing distinct jobs reads faster than a gray one.
- When the project has a design system, push its palette to its most expressive range. When it has none, pick a bold one and apply it consistently.

## Creativity

- Explore distinct directions. When building several mocks, make each a different idea (palette, layout, type, illustration), so the pick is a real choice.
- Use expressive typography, illustration, iconography, and considered micro-interactions to give the UI character.
- Prefer the surprising option that works over the safe one that blends in.

## Usability

Vibrancy serves the user. Keep text contrast at WCAG AA or better, keep interactive states obvious, and pair color with a label or icon wherever it carries meaning.
